LUMINARK is an experimental collection of software prototypes organized around the owner's 0-9-0 / SAP framework. The repository contains rule-based stage classification, selected neural-network experiments, optional Qiskit circuit examples, heuristic text-pattern checks, and prototype interfaces.

## Quantum code: important distinction

The repository includes a Qiskit module that constructs and executes quantum circuits. That establishes the presence of experimental quantum-computing code. It does not establish that those circuits verify truth, measure semantic coherence, improve model reasoning, or outperform classical methods. The character-to-rotation encoding and resulting measurement statistics require a defined mathematical rationale and controlled evaluation before stronger claims can be made.

Other components, including my_quantum_ai.py, use conventional PyTorch operations and synthetic data; they do not perform quantum computation.
